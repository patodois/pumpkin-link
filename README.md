# pumpkin-link

A plugin for the [Pumpkin](https://github.com/Pumpkin-MC/Pumpkin) Minecraft server that speaks the
rewrite-bridge passthrough link protocol (`docs/CONTRACT.md` in
[rewrite-bridge](https://github.com/patodois/rewrite-bridge)). Work in progress.
